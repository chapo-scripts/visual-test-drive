# Template project for moonly
## Used modules
* **[moonly](https://www.blast.hk/threads/220380/)** *(development only)*
* **[carbJsonConfig](https://www.blast.hk/threads/214849/)** - Config system
* **[mimgui](https://www.blast.hk/threads/66959/)** - User Interface

## Development
1. `git clone https://github.com/chapo-scripts/moonly-mimgui-template`
2. `code moonly-mimgui-template`
3. add your shitcode
4. commit changes using
    ```bash
    git add .
    git commit -m 'commit message'
    git push
    ```

## Building
1. Install **[moonly-cli](https://github.com/themusaigen/moonly-command-tool)**
2. Run `moonly.exe bundle`
